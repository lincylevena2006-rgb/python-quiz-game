# 🧠 Python Quiz Game

A simple command-line quiz game built using Python.

## Features

- 5 multiple-choice questions
- Instant answer checking
- Score calculation
- Final result display
- Beginner-friendly Python project

## Concepts Used

- Lists
- Dictionaries
- For loops
- If-else statements
- User input
- String methods

## How to Run

```bash
python quiz_game.py
